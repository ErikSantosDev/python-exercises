# 🐍 Desafios de Python - Curso em Vídeo

Repositório dedicado aos exercícios e desafios práticos desenvolvidos durante o curso de **Python 3** do canal Curso em Vídeo, ministrado pelo professor Gustavo Guanabara. 

O objetivo deste projeto é registrar a minha evolução na lógica de programação, versionamento de código e resolução de problemas.

---

## 🛠️ Tecnologias e Ferramentas
- **Python 3**
- **VS Code** (Ambiente de Desenvolvimento)
- **Git & GitHub** (Controle de versão)

---

## 📂 Estrutura de Aprendizado

Atualmente, o repositório está organizado da seguinte forma:

### 🔹 [Mundo 1](./mundo-1/) - Fundamentos
Primeiro contato com a sintaxe e a lógica da linguagem.
- **Conceitos:** Tipos primitivos, operadores aritméticos, uso de módulos/bibliotecas (`math`, `random`) e tratamento de strings.
- **Condicionais:** Estruturas básicas de `if/else`.
- *Destaques:* Criando os primeiros scripts de cálculo e validadores simples.

### 🔹 [Mundo 2](./mundo-2/) - Estruturas de Controle
Foco em fluxos lógicos e automação de repetições.
- **Condicionais Avançadas:** Uso de estruturas aninhadas (`if/elif/else`).
- **Laços de Repetição:** Dominando as estruturas de iteração `for` e `while` (com interrupções via `break`).
- *Destaques:* Desenvolvimento de jogos textuais interativos (como Jokenpô e Adivinhação).
